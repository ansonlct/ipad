# My Day v5.20 — Hong Kong Dashboard

A single-page 16-widget dashboard for iPad and Windows browsers, deployable on GitHub Pages.

### Version 5.19
- Tap the clock to toggle 24-hour and 12-hour (AM/PM) time.
- Larger first-bus ETA while maintaining aligned arrival-time rows.
- New stock web shortcuts: YouTube, Gemini, HK01 HTTPS, Cambridge Chinese Traditional dictionary.
- Important dates empty card reacts to mouse hover, matching the reminders card.

Installation: `INSTALL_STEPS_HK.txt` — Acceptance: `TEST_REPORT_v5_19.txt`.

Local settings are browser-specific; live external sources require network connectivity.
