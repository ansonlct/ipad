# My Day v5.24 — 專案交接
2026-11-04 | 基礎：v5.23 | 最新 ZIP：MyDay_v5_24_UnifiedWidgetTitles.zip

## 本版修改（唯一新功能）
把所有 16 個有視覺標題的 Widget，依相對濕度標題統一為一套規格：
- 平台字體：原本 `-apple-system` / `BlinkMacSystemFont` / `SF Pro Display` / `PingFang HK` 字體堆疊
- 字號：`calc(12px * var(--font-scale))`（個人化「小／中／大」全部同步縮放）
- 字重：760；字距：-0.025em；行高 1.2；標題透明度：1
- 標題行左／上 11px（卡片外邊框起算，包括邊框 1px）
- 圖示統一 24×24px，與文字相隔 6px；沒有圖示的月曆月份直接從左 11px 起
- 字色使用 `var(--ink)`；深藍色即時天氣 Widget 例外，白色標題以維持對比

**涵蓋的 16 張卡：** 即時天氣、相對濕度、氣壓、能見度、UV、風向風速、天氣警告、九巴、日照、潮汐、我的提醒、重要日子、未來天氣、恒指、即時新聞、月曆。沒有標題的日期／時鐘／計時器／捷徑沒有變動。

所有標題文本 DOM 元素加上 `.widget-heading`；共用 CSS 加在 `index.html` 底部 `/* v5.24 ... */` 區段。已有 heading 外容器如 `.section-head`、`.meteo-title`、`.ios-weather-top` 等仍保留原 DOM 及功能，透過小幅 CSS relative offset 使不同 padding 的卡片標題起點一致，無須重構卡片內部排版。保留右側操作圖示及 tag。窄 820px 直向版天氣標題預留操作箭頭位置。

## 相容性／須維持的功能
保留全部 20 Widget、自動分頁及右側垂直圓點、上下 swipe/滑鼠滾輪/鍵盤換頁動畫、時間設定、天氣數據來源、資料不足顯示 `--`、統一來源小字 footer、九巴來源 footer、計時器、提醒、重要日子、月曆標記及 localStorage，不增添外部前端 runtime。
